# LANDING COPY SKILL

Objectif :

Créer un copywriting persuasif mais honnête pour le Guide Africain de Nutrition.

Ordre obligatoire :

Hero
→ problème
→ ancienne/nouvelle méthode
→ mécanisme
→ bénéfices
→ contenu de l’offre
→ situations réelles
→ fonctionnement
→ FAQ
→ offre
→ CTA final.

Toujours partir du problème réel :

difficulté à organiser les repas,
portions,
choix,
cuisson,
organisation.

Ne pas transformer le produit en traitement médical.

Écrire pour une personne froide qui ne connaît pas la marque.

Chaque titre doit être compréhensible sans contexte.

Éviter le jargon marketing visible par le client.

Avant de modifier le copywriting, vérifier que chaque affirmation existe réellement dans le livre ou est une formulation raisonnable d’une information déjà présente.

Ne jamais fabriquer de preuve sociale.
