IMAGE ASSETS SKILL

Scanner :

/public/images/

Classer les images en :

hero,
plats,
recettes,
pages du livre,
offre,
décoration.

Ne jamais utiliser une URL distante.

Créer une structure de données permettant à la page de présenter facilement les images.

Générer des alt text utiles.

Préserver les proportions réelles.

Optimiser les images lorsque nécessaire.

Ne pas dégrader les images de couverture ou les pages du livre.

Créer :

un hero image,
un carousel plats,
un aperçu du livre,
une galerie ou pile de pages,
des images contextualisées dans les bénéfices.

Les images de plats doivent être visuellement cohérentes.

Le système doit fonctionner même si certaines images optionnelles sont absentes.
