# UI RULES

Concevoir d’abord pour smartphone.

Le contenu doit fonctionner parfaitement à 375–430 px.

Utiliser une hiérarchie forte :

petite accroche,
grand titre,
sous-titre court,
CTA,
preuve visuelle.

Utiliser beaucoup d’espace blanc.

Les photos de plats doivent être grandes, appétissantes et réelles.

Les cartes doivent rester simples.

Les boutons doivent avoir une zone tactile généreuse.

Utiliser des animations d’entrée discrètes :

fade,
slide court,
scale léger.

Ne jamais utiliser d’animation qui retarde le contenu.

Utiliser des sections avec variation de rythme visuel :

texte,
image,
cartes,
carousel,
aperçu du livre,
offre.

Le mobile doit rester fluide même avec une connexion moyenne.

Le CTA principal peut être sticky en bas de l’écran mobile, mais il ne doit jamais masquer le contenu ou bloquer la lecture.
