## POSITIONNEMENT

Le message central est :

« Tu n’as pas besoin d’abandonner le riz, l’igname, le manioc ou le plantain pour mieux manger. »

Le mécanisme proposé est :

Mieux composer son assiette
+
mieux gérer les portions
+
mieux choisir les modes de cuisson
+
mieux organiser ses repas
+
utiliser des aliments locaux.

## CRÉDIBILITÉ

Ne jamais fabriquer :

avis,
résultats clients,
nombre de clients,
notes,
avant/après réels,
statistiques commerciales.

## SANTÉ

Ne jamais transformer le guide en prescription médicale.

Ne jamais promettre :

un nombre précis de kilos perdus,
la guérison d’une maladie,
la régulation garantie d’une glycémie,
la baisse garantie d’une tension,
une transformation médicale.

Le produit est un guide général d’organisation alimentaire.
